# CLAUDE.md

Next.js (App Router) + TypeScript + Tailwind CSS 4, scaffolded with next-starter.
Code standards are enforced by Ultracite (Biome); see `.claude/CLAUDE.md`.

## Rules

- Use pnpm.
- Do NOT run build, dev, or deploy commands unless I specifically tell you to.

## Commands

- `pnpm dev` - development server
- `pnpm check` - lint + format check (Ultracite)
- `pnpm fix` - auto-fix lint + format
- `pnpm typecheck` - generate route types, then `tsc --noEmit`

## Conventions

- `@/` absolute imports.
- Server Components by default; add `"use client"` only for interactivity.
- Pages default-export a component named `Page` typed with `PageProps<"/route">`; layouts use `LayoutProps<"/route">` (global types generated by `next typegen`).
- `params` and `searchParams` are Promises; await them.
- Server actions end with `Action` and return `ServerActionResponse<T>` from `@/types`.
- Compose class names with `cn` from `@/lib/utils`.
- Environment variables: add them to the schemas in `lib/env.ts` and read them from `env`, not `process.env`.
- Site name, description and SEO defaults live in `lib/metadata.ts`.
- URL search-param state: use `nuqs` (install it and wrap the root layout in `NuqsAdapter` from `nuqs/adapters/next/app` the first time it is needed).
